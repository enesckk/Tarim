# Reminder Rules Configuration

## Overview
Reminder rules define the operational thresholds for when system tasks trigger notifications. 

## Default Rules
- **3 Days Before**: Notifies users 3 days prior to a task's due date.
- **1 Day Before**: Notifies users 1 day prior to a task's due date.
- **On Due Date**: Notifies users on the exact day the task is due.
- **1 Day Overdue**: Triggers if the task is not completed 1 day after the due date.
- **Daily Critical Reminder**: If a critical task remains overdue, a daily reminder is sent until completion.

## Disclaimer
These triggers are defined as operational defaults, NOT agricultural scientific thresholds. Administrators can update or disable these rules based on platform engagement metrics.
