# Üretici PWA

Mağaza indirmeden tarayıcıdan **Ana ekrana ekle** ile kullanılan üretici uygulaması.

- Yerel: `http://127.0.0.1:5174/login`
- `npm start` (repo kökü) ile birlikte ayağa kalkar
- Bildirimler: Web Push (VAPID) + uygulama içi bildirim listesi

```bash
cd producer-web
npm install
npm run dev
```

Demo: `5537472823` / `asd` (veya `uretici@agriculture.local`)
